# Ask VeilCore: the 60-second demo

For showing Ask to someone. Run it on the **test site** (`npm run deploy:test`, docs/test-site.md),
on a Midnight **test network**. Ask is not on veilcore.org yet: say "on the test network", never
"live".

## Set up first (5 minutes, before anyone is watching)

1. On the test site, in a fresh browser profile, log one plant named **Blue Dream #12** (bred by
   your farm name). Save the backup and check it. Let the key date stamp finish.
2. Make **one agreement with a due date**: on Blue Dream #12, Agreements → a license with
   quarterly reports, a start date a few months back, so a report and a payment are due soon.
   Have the other side accept it in a second browser profile, so it is live. ("What's due" reads
   only live agreements.)
3. Phone or a narrow window: the sheet opens from the bottom, as most growers will see it.
4. Keep the backup file to hand: saving a batch asks for it again.

## The 60 seconds

| Time | Do | Say |
| --- | --- | --- |
| 0:00 | Open Your records. Tap **Ask**. | "Ask is built into the page. Typing here sends nothing; only Save does. It works offline." |
| 0:08 | Type `cut 6 clones from Blue Dream #12`, tap Go. | "Plain words, five languages. It found my plant and the number." |
| 0:15 | Tap **Open it**. Point at the highlighted fields. | "It opens the real screen with the fields marked. I check them; nothing is saved yet." |
| 0:22 | Next → save the backup (open the saved copy) → **Save 6 records**. | "Each clone names its parent inside its own locked record. Six records, one Save." |
| 0:35 | Open one clone's page. Scroll to an on-chain step (Prove you hold it, or the seal screen of a new record) and point at **What this puts on Midnight**. | "Before anything goes on Midnight, it says exactly what becomes public, read from the contract itself. My genetics never leave this device unlocked." |
| 0:45 | Ask → **What's due**. | "From the agreement's terms in this browser: the next report and payment." |
| 0:52 | Tap **Add to my calendar**, then **Share a reminder**. | "The reminder only says how many are due. No names, no amounts." |
| 0:60 | | "Drafts on your device. You save. That's Ask." |

## If something goes wrong

- **The clones open with no plant picked**: the name didn't match. Pick Blue Dream #12 in "Cut
  from"; say "it only fills in records I logged myself and named".
- **What's due is empty**: the agreement isn't live yet (accepted and activated) or its first
  period hasn't ended. Show the Explain chip instead ("Proof code").
- **The date stamp is still running**: that's the network; the record is already sealed and
  saved. Carry on.

Don't show names of real people or organisations, and don't say "own" or "ownership": a record
shows prior possession by a date.
