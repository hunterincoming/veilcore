What this does not show

  • That anything the record says is true: the name, who bred it, the stated date. The breeder wrote those.
  • That the document is genuine, that the issuer named in it issued it, or that what it says is true. The title, type, issuer and dates are the holder’s statements. A file that matches shows only that a file with exactly those bytes was in the holder’s hands by the date.
  • Who holds the plant or the record now.
  • That a signing key belongs to the lab it names. VeilCore doesn’t vouch for anyone, and neither does this page.
  • What a lab’s sample was. The lab tested the sample it received under this record. This result doesn’t show who took the sample or that it came from this record’s material, and it applies only to the portion tested.
  • Any date at all, until a date in this bundle checks: the Midnight transaction, the Bitcoin stamp or the RFC 3161 token. Until then the files only agree with each other.
  • That Bitcoin’s network agrees today: this page reaches no network. When this bundle carries the stamped block’s header (proof/bitcoin-headers.json), the page checks the block holds the value the stamp file names, has Bitcoin’s proof of work, and links to a block this page pins; without it, the page only reads the stamp file.
  • When a lab report was saved to the plant. That came after sealing and isn’t inside the record’s proof code, so the batch doesn’t date it.
