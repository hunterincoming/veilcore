What this does not show

  • That anything the record says is true: the name, who bred it, the stated date. The breeder wrote those.
  • Who holds the plant or the record now.
  • That a signing key belongs to the lab it names. VeilCore doesn’t vouch for anyone, and neither does this page.
  • Any date at all, until you find the batch root in the transaction named above (or the Bitcoin stamp checks). Until then the files only agree with each other.
  • The Bitcoin block itself: this page reads the stamp file, but it can’t reach Bitcoin to see that the block holds the value the file names.
  • When a lab report was saved to the plant. That came after sealing and isn’t inside the record’s fingerprint, so the batch doesn’t date it.
